# МегаНатс

Локальная витрина магазина орехов и сухофруктов. Откройте `index.html` в браузере или выполните в терминале VS Code из корня папки `MegaNuts`:

```sh
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

В `products.js` хранятся товары, предварительные цены, фасовки и характеристики. Для дополнительных фасовок у одного товара используются отдельные позиции в `variants`. В корзине они учитываются отдельно. Корзина сохраняется в браузере, список покупок можно скачать.

Страница `contacts.html` открывается по ссылке «Контакты» в верхней полосе, мобильном меню и подвале. Телефон, почта, адрес и график пока заменены заглушками; кнопка отправки формы отключена. Корзина и переходы к категориям работают на обеих страницах.

Общий набор контурных иконок хранится в `assets/icons.svg`. В статических страницах он используется через SVG `use`, в динамических блоках — через функцию `icon()` в `app.js`.

Оформление работает в тестовом режиме: контакты, доставка или самовывоз, расчёт итога и скачивание тестового заказа. Тариф 350 ₽ используется только для проверки расчёта. Для приёма заказов нужны цены и остатки «МегаНатс», зона и тарифы доставки, адрес самовывоза и подключение канала приёма заказов. Контакты тестового заказа не отправляются и не сохраняются в браузере после закрытия оформления.

Референс оформления и часть фотографий — [Tierra Farm](https://www.tierrafarm.com/). Товары, предварительные цены и доступные характеристики — [Frutoss](https://frutoss.ru/). Иллюстрации созданы в ImageGen и сохранены в `assets/catalog`. [Промпты изображений](PHOTO-PROMPTS.md). Исходный логотип находится в `assets/logo.png`.
